## 1. Overview & Architectural Isolation

ApiProber is engineered as a zero-dependency, local-first Python CLI for ethical and passive REST API discovery. It operates 100% locally on the operator's workstation, persisting all discovery state into a local SQLite database (`data/api_prober.db`) without requiring external cloud accounts, proprietary daemon processes, or background telemetry.

### 1.2 Unprivileged RunAsInvoker Non-Elevation Certification

ApiProber is certified to execute within an unprivileged standard user context (`RunAsInvoker`). It requires no administrative or root privileges, never touches protected system directories (`System32`, `/etc`, `Program Files`), and restricts all file writes strictly to user-designated output paths or the local `data/` and `exports/` directories.
